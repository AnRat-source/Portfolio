RACS roadmap

Current systems and what’s next.

Rat’s Advanced Combat System is being built as a configurable combat framework with system-level depth across weapons, interaction, and environment work.

Core features

Combat foundation

  • Default ACS enhancements with optimized performance
  • Advanced AI inspired by Ready or Not
  • Server-calculated procedural arm animation
  • Bullet and RPG defaults with projectile support
  • Zoomable scopes with adjustable range
Customization

Project-ready tools

  • Configurable inventory and gear systems
  • Drag-and-drop modding system for paid builds
  • Node-friendly gunsmith attachments
  • Viewmodel override support for FE Gunkit and ACS models
  • BRM5-inspired UI and effects
Interaction & environment

World systems

  • Ready or Not-style door breaching
  • Spearhead-style item drops and mountable turrets
  • Healing, squad, and emote interaction menu
  • First- and third-person gun handling
  • Realistic grenades and voice-chat radio integration
Upcoming

In development

  • R15 gore with hit-dependent PBR models
Release notes

Development log.

Tracked milestones for Rat ACS, starting from Alpha 0.1.2 and continuing through the current framework revamp.

26 Nov 2024Alpha 0.1.2

Stability, mods, and the first tracked update.

Performance work focused on keeping combat interactions stable, alongside new modding capability and a larger weapon roster.

  • Optimized fire and Molotov behavior
  • Added drag-and-drop body camera mod
  • Restored blood textures
  • Expanded the modding API
  • Added Desert Eagle, .357 Magnum, AA-12, M249, SCAR-H, and RPG-7
  • Updated M4A1 and MP5
4 Feb 2026Alpha 1.1.0

Framework revamp and broader combat systems.

A major update centered on attachment handling, gore support, optimized physics, and AI interaction with mounted weapons.

  • Revamped attachment system
  • Added universal R15 and R6 gore engine
  • Added thermal vision
  • Added work-in-progress mesh-wrapped bullet holes
  • Moved grenades to mathematical calculation
  • Enabled AI NPC weapon mounting
  • Fixed physics and improved optimization
  • Doubled FPS in certain playtests
  • Added Barrett .50, Dragunov, and X16
  • Updated all older guns for the revamped framework
